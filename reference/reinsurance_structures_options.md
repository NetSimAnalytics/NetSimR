# A vector with the reinsurance structure options

The names of the reinsurance structures that
[`apply_deductible_limit`](https://netsimanalytics.github.io/NetSimR/reference/apply_deductible_limit.md)
and
[`simulate_function`](https://netsimanalytics.github.io/NetSimR/reference/simulate_function.md)
accept, used by the simulator app as the choices of its structure inputs
and to validate saved settings.

## Usage

``` r
reinsurance_structures_options
```

## Value

The reinsurance structure options
