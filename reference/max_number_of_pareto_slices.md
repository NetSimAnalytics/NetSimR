# Parameter to set the maximum number of Pareto slices

The largest number of Pareto slices that the simulator app and
[`simulate_claims`](https://netsimanalytics.github.io/NetSimR/reference/simulate_claims.md)
accept, so that the app can build one row of slice inputs for each.

## Usage

``` r
max_number_of_pareto_slices
```

## Value

The maximum number of Pareto Slices.
