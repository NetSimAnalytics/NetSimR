How to read this report

  • The deviance per row measures how far the predictions are from the actual values: on rows held out it shows how the model does on data it has not seen.
  • The Gini coefficient measures how well the predictions rank the rows, from 0 (no better than chance) up.
  • The rate table gives every prediction as a base rate times a relativity for each rating factor, so a rating engine can price with it.
